
# java-proyects

This repository contains a collection of Java, Kotlin, Scala, and related projects, organized by technology and use case. Each subdirectory represents a different module or technology stack, such as AWS integrations, Scala Akka projects, Solidity smart contracts, and more.

## Structure

- **aws/**: Java/Kotlin projects for AWS integrations.
- **aws-dynamo-db/**: AWS DynamoDB related code and examples.
- **aws-sqs/**: AWS SQS (Simple Queue Service) related code and examples.
- **docker/**: Docker and Docker Compose files for local development and testing.
- **python/**: Python scripts and exercises, including basic programming tasks and data processing.
- **quartz/**: Projects related to Quartz Scheduler.
- **scala/**: Scala projects, including Akka, Akka HTTP, Akka Persistence, and advanced Scala topics.
- **solidity/**: Solidity smart contract projects and related tooling.
- **users-api/**: Example API project, likely in Java/Kotlin.

## Getting Started

Each subproject contains its own build files and instructions. Please refer to the respective `README.md` files within each subdirectory for more details on setup and usage.

## Requirements

- Java 11 or higher (for Java/Kotlin projects)
- Scala (for Scala projects)
- Python 3 (for Python scripts)
- Docker (for containerized environments)
